# strymy-bot

Сборщик состояния беларуских Twitch-стримеров для раздела `mashninski.com/strymy`.

Раз в 10 минут спрашивает Twitch, кто в эфире, ловит момент окончания стрима, ищет запись
и пишет результат в `data/twitch-state.json`. Сайт читает этот файл и не пересобирается от его изменений.

## Структура

```
streamers.json                  реестр: кого показываем, соцсети, заметки — правится руками
collect.py                      сборщик
data/twitch-state.json          состояние, пишет бот, руками не трогать
.github/workflows/collect.yml   cron раз в 10 минут
```

## Настройка

1. Репозиторий должен быть **публичным** — на приватном Actions съедят бесплатный лимит минут
   примерно за две недели.
2. Settings → Secrets and variables → Actions → New repository secret:
   - `TWITCH_CLIENT_ID`
   - `TWITCH_CLIENT_SECRET`
3. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
   Без этого бот не сможет закоммитить состояние.
4. Actions → collect → **Run workflow** — первый прогон вручную, чтобы убедиться, что всё живо.

## Реестр

```json
{
  "streamers": [
    { "login": "nickname", "note": null, "socials": {}, "tags": [], "featured": false, "hidden": false }
  ]
}
```

`login` — то, что стоит в адресе канала `twitch.tv/<login>`, строчными буквами.
`hidden: true` убирает стримера из сбора и с сайта, не удаляя историю.

## Локальный запуск

```bash
pip install requests
export TWITCH_CLIENT_ID=...
export TWITCH_CLIENT_SECRET=...
python collect.py
```

`FORCE_VOD_CHECK=1` заставляет проверить записи вне расписания (обычно это делается
в первом прогоне каждого часа).

## Что нужно знать при обслуживании

- **Коммит только при изменениях.** Прогон, в котором ничего не поменялось, файл не трогает.
  Поэтому в истории репозитория примерно столько коммитов, сколько было стримов.
- **GitHub гасит cron в публичном репозитории после 60 дней без активности.** Пока стримы идут,
  бот коммитит сам и активность есть. Если каталог надолго замрёт — проверить, что воркфлоу включён.
  GitHub присылает письмо перед отключением.
- **Точность длительности — ±10 минут** для тех, кто не сохраняет VOD. У остальных длительность
  берётся из записи и точна до секунды.
- **`stale: true`** у стримера означает, что Twitch не отдаёт канал шесть прогонов подряд:
  бан, удаление или смена логина. Карточку в этом случае прячем.
